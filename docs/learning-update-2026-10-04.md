# Listening that transfers — October 4, 2026

This update follows the review sequence: reliability, recall scheduling, recommendations, focused listening, real-world practice, and recording comparisons/pathways.

## Where to find it

- Today: starting difficulty, interests, goals, time budget, shared recommendation logic, and French practice pathways. Preferences suggest activities; they never lock content or certify a CEFR level.
- Phrase review: hear/understand, meaning or source-context recall, and sentence gaps. Again returns in ten minutes; successful ratings expand the interval with explicit bounds. These are transparent heuristics, not a retention prediction.
- Decode: name and save exact A–B excerpts from the original lesson recording. An excerpt needs the lesson audio loaded. Sentence-level AI narration remains explicitly labeled and separate.
- Library → French listening lab: eight dictations with hints/transcript support and two three-turn service missions. These log practice completion, not tested spontaneous-speaking proficiency.
- Library → Original voices: official TV5MONDE / Radio Sweden links and a per-language synced notes notebook. Media stays on the publisher's site. YouTube content can use the existing Studio loop; captions are not guaranteed and are not a fresh audio transcription.
- Recording controls: explicitly opt in to saving an audio take and transcript. Library → Recording journal compares two saved takes and supports permanent deletion. Twenty private recordings per account per language, eight MB per recording; metadata uses D1 and audio uses the private R2 binding. No automatic recording retention or public audio URL.

## Reliability and evidence

- Merge histories newest-first before applying display caps.
- Cancel stale Swedish audio loads; cached speech still requires authentication but does not consume paid-generation quota.
- Familiar announcement retries keep their own history without becoming new first-listen evidence; duplicate submissions preserve their original result.
- Capability evidence uses specific questions rather than every answer from a broadly related activity.
- Recommendations prefer recent reflections and the latest relevant listening evidence; older aggregate reflections remain a fallback for existing accounts.
- Speaking coaching is transcript/timing based, permits no correction when appropriate, and no longer presents a CEFR estimate. It does not evaluate phonemes directly.

## Verification and boundaries

Automated tests cover review intervals, merging, question evidence, French exercise structure, stale audio cancellation, cache quota behavior, release acknowledgements and the recording API's consent/authentication/ownership/language/limit/deletion behavior. Existing learning-loop, sync, rehearsal, and content tests remain in the test command.

Browser-control support was unavailable during this implementation. Build, rendered-page and API checks do not replace listening on a real device. The original-publisher links are an authentic-media foundation, not a newly licensed or hosted native-speaker catalog. The service missions are authored choices with tailored replies, not unrestricted AI conversation. French/Swedish XP accounting remains unchanged and separate on the backend.
